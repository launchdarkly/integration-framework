# Mezmo

User documentation for this integration is available on the LaunchDarkly documentation site: [Mezmo](https://launchdarkly.com/docs/integrations/mezmo)

API documentation for this integration is available on the Mezmo API documentation site: [Mezmo](https://docs.mezmo.com/telemetry-pipelines/api-references)

## Getting started with the Mezmo integration

Run `npm run curl logdna` in the root repository directory to generate a `curl` command to send data to Mezmo.
